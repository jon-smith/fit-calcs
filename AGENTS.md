# Repository Guidelines

## File Naming

- Use `UpperCamelCase.tsx` for React component files.
  - Examples: `App.tsx`, `NRepMaxCalculator.tsx`, `RunningPaceCalculator.tsx`.
- Use `kebab-case.ts` for non-component TypeScript source files.
  - Example: `running-pace-math.ts`.
- Keep framework and tool configuration files in their ecosystem-standard names.
  - Examples: `vite.config.ts`, `tsconfig.json`.

## Validation

- Run `npm run check` before handing off changes.
